# MeetingProtocols — сайт протоколов собраний Эльгауголь

## Деплой на Render.com

1. Загрузи этот проект в репозиторий на GitHub
2. Зайди на render.com → New → Web Service
3. Подключи репозиторий
4. Render сам найдёт Dockerfile
5. Нажми Create Web Service
6. Через 2-3 минуты сайт будет доступен по адресу вида `https://elgauqol-protocols.onrender.com`
